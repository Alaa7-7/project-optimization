Project: Numerical Simulation and Optimization of Advection–Diffusion Equation

Description:
Developed a numerical solver for the 1D Advection–Diffusion equation using Finite Difference Method. Implemented parameter optimization to estimate velocity and diffusion coefficients.

Key Skills:
- Python scientific computing (NumPy)
- Numerical PDE solving
- Optimization techniques (grid search)
- Data analysis

Tools:
- Python
- NumPy
- Git / GitHub

Outcome:
- Stable numerical simulation
- Parameter estimation model
- Scientific report (PDF)
- Visualization and animation of diffusion process
