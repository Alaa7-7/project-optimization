\begin{abstract}
This project studies how to estimate unknown parameters in the Advection--Diffusion equation using numerical simulation and simple optimization methods.
\end{abstract}

\section{Introduction}

This project focuses on estimating unknown values from a mathematical model using simulation.

The project includes:
\begin{itemize}
\item Solving a PDE numerically
\item Generating sample data
\item Using optimization methods to find parameters
\end{itemize}

\section{Mathematical Model}

The main equation is:

\begin{equation}
\frac{\partial u}{\partial t}
+
v \frac{\partial u}{\partial x}
=
D \frac{\partial^2 u}{\partial x^2}
\end{equation}

where:
$u(x,t)$ is the main variable,  
$v$ is velocity,  
$D$ is diffusion.

\section{Numerical Method}

We approximate derivatives as:

Advection:
\begin{equation}
\frac{\partial u}{\partial x} \approx \frac{u_i - u_{i-1}}{\Delta x}
\end{equation}

Diffusion:
\begin{equation}
\frac{\partial^2 u}{\partial x^2} \approx \frac{u_{i+1} - 2u_i + u_{i-1}}{\Delta x^2}
\end{equation}

Time update:
\begin{equation}
u^{n+1} = u^n + \Delta t \cdot (\text{advection + diffusion})
\end{equation}

\section{Inverse Problem}

We try to find $v$ and $D$ by minimizing the error:

\begin{equation}
J(v,D) =
\left\| u_{sim} - u_{obs} \right\|^2
\end{equation}

\section{Optimization Methods}

\subsection{Genetic Algorithm}
A method that searches using population, selection, and mutation.

\subsection{Particle Swarm Optimization}
A method that improves solutions using best previous results.

\section{Experimental Setup}

True values:
\begin{itemize}
\item $v = 0.8$
\item $D = 0.05$
\end{itemize}

\section{Results}

PSO gave good results:
\begin{itemize}
\item $v \approx 0.80$
\item $D \approx 0.05$
\end{itemize}

\section{Conclusion}

This project shows that simple optimization methods can be used to estimate unknown parameters in a PDE model.
